# my-site

A small hand-written personal website: five pages, shared navigation and footer, and a useless machine.

## Pages
- `index.html` — homepage
- `quotes.html` — quotes with a random picker and likes
- `project.html` — project ideas
- `about.html` — about and contact
- `machine.html` — the useless machine

## Built with
Plain HTML, CSS and JavaScript. Navigation and footer are shared through `nav.html` and `footer.html`, injected by `nav.js`.

## Run locally
Open with VS Code's Live Server — the shared navigation needs http://, not file://.
